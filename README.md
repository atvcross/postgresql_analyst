# База данных для книги «SQL для аналитика. 50 задач с решениями на PostgreSQL»

## Установка схемы

Этот репозиторий содержит файл `market.sql` — готовую базу данных для практических задач книги.

### Требования

- PostgreSQL 15 или выше
- pgAdmin (опционально, для графического интерфейса)

### Быстрая установка

1. Скачайте файл `market.sql` из репозитория.

2. Создайте базу данных:

```sql
CREATE DATABASE book_analytics;
Загрузите схему:

bash
psql -U postgres -d book_analytics -f market.sql
Установка через pgAdmin
Откройте pgAdmin.

Создайте новую базу данных book_analytics.

Откройте Query Tool для этой базы.

Загрузите файл market.sql (кнопка Open File).

Нажмите Execute (F5).

Проверка установки
Выполните проверочный запрос:

sql
SELECT COUNT(*) FROM users;
Должно вернуться 15.

Структура базы данных
База данных интернет-магазина состоит из 8 таблиц:

Таблица	Описание
users	Пользователи (id, имя, дата регистрации, страна)
categories	Категории товаров (иерархическая, с parent_id)
products	Товары (название, цена, привязка к категории)
orders	Заказы (пользователь, дата, статус, даты доставки)
order_items	Состав заказа (товар, количество, цена)
payments	Платежи (сумма, дата, способ оплаты)
users_log	Лог событий (действия пользователей, время, JSONB)
user_comments	Отзывы (текст, оценка, дата)
Возможные проблемы
Ошибка: база book_analytics уже существует

sql
DROP DATABASE book_analytics;
CREATE DATABASE book_analytics;
Ошибка: permission denied

Запустите pgAdmin или psql от имени администратора.

Пустой результат при проверке

Выполните скрипт market.sql ещё раз.
