Глава 4. Продвинутый SQL

Задание: Напишите запрос, который выводит общую сумму выручки по каждому пользователю (user_id, user_name) и название страны, но только для пользователей из России и Казахстана. Используйте JOIN и WHERE с IN. Результат отсортируйте по сумме от большей к меньшей.

Ответ:

text
SELECT 
    u.user_id,
    u.user_name,
    u.country,
    SUM(oi.quantity * oi.price_per_unit) AS total_revenue
FROM users u
JOIN orders o ON u.user_id = o.user_id
JOIN order_items oi ON o.order_id = oi.order_id
WHERE o.status = 'completed'
  AND u.country IN ('Россия', 'Казахстан')
GROUP BY u.user_id, u.user_name, u.country
ORDER BY total_revenue DESC;

Глава 6. CTE. Конверсия из регистрации в покупку

Задание: Напишите запрос, который считает конверсию из регистрации в покупку для пользователей, зарегистрировавшихся в 2024 году. Используйте CTE.

Ответ:

text
WITH all_users AS (
    SELECT COUNT(*) AS total FROM users WHERE EXTRACT(YEAR FROM registered_at) = 2024
),
buying_users AS (
    SELECT COUNT(DISTINCT o.user_id) AS buyers
    FROM orders o
    JOIN users u ON o.user_id = u.user_id
    WHERE EXTRACT(YEAR FROM u.registered_at) = 2024
)
SELECT 
    buyers,
    total,
    ROUND(100.0 * buyers / total, 2) AS conversion_rate
FROM all_users, buying_users;

Глава 8. GROUP BY, AVG. Средний чек по категориям

Задание: Напишите запрос, который выводит средний чек по категориям для заказов, сделанных в феврале 2024 года. Используйте фильтр по дате и группировку.

Ответ:

text
SELECT 
    c.name AS category_name,
    ROUND(AVG(oi.price_per_unit * oi.quantity), 2) AS avg_order_value
FROM orders o
JOIN order_items oi ON o.order_id = oi.order_id
JOIN products p ON oi.product_id = p.product_id
JOIN categories c ON p.category_id = c.category_id
WHERE o.status = 'completed'
  AND o.order_date BETWEEN '2024-02-01' AND '2024-02-29'
GROUP BY c.category_id, c.name
ORDER BY avg_order_value DESC;

Глава 11. DATE_TRUNC, SUM, кросс-таблицы. Выручка по месяцам

Задание: Напишите запрос, который строит кросс-таблицу выручки по кварталам (используйте DATE_TRUNC('quarter', order_date)) и категориям «Ноутбуки», «Смартфоны», «Планшеты».

Ответ:

text
CREATE EXTENSION IF NOT EXISTS tablefunc;

SELECT * FROM crosstab(
    'SELECT 
        DATE_TRUNC(''quarter'', o.order_date)::date AS quarter,
        c.name AS category_name,
        SUM(oi.quantity * oi.price_per_unit) AS revenue
    FROM orders o
    JOIN order_items oi ON o.order_id = oi.order_id
    JOIN products p ON oi.product_id = p.product_id

      AND c.name IN (''Ноутбуки'', ''Смартфоны'', ''Планшеты'')
    GROUP BY quarter, c.category_id, c.name
    ORDER BY 1,2',
    'SELECT DISTINCT name FROM categories WHERE name IN (''Ноутбуки'', ''Смартфоны'', ''Планшеты'') ORDER BY 1'
) AS ct(quarter date, "Ноутбуки" numeric, "Смартфоны" numeric, "Планшеты" numeric);


Глава 12. Аналитические функции. Топ-5 товаров

Задание: Напишите запрос, который выводит топ-2 товара по выручке в каждой категории. Используйте ROW_NUMBER() OVER (PARTITION BY ...).

Ответ:

text
WITH product_revenue AS (
    SELECT 
        c.name AS category_name,
        p.product_id,
        p.name AS product_name,
        SUM(oi.quantity * oi.price_per_unit) AS revenue
    FROM order_items oi
    JOIN products p ON oi.product_id = p.product_id
    JOIN categories c ON p.category_id = c.category_id
    GROUP BY c.name, p.product_id, p.name
),
ranked AS (
    SELECT 
        category_name,
        product_name,
        revenue,
        ROW_NUMBER() OVER (PARTITION BY category_name ORDER BY revenue DESC) AS rank
    FROM product_revenue
)
SELECT 
    category_name,
    product_name,
    revenue,
    rank
FROM ranked
WHERE rank <= 2
ORDER BY category_name, rank;


Глава 13. Аналитические функции. Retention 7 дней

Задание: Посчитайте retention за 7 дней, но используйте только покупки (users_log с action = 'buy'). Измените фильтр в user_activity.

Ответ:

text
WITH user_activity AS (
    SELECT 
        u.user_id,
        u.registered_at::date AS reg_date,
        DATE(l.dt_tm) AS activity_date
    FROM users u
    JOIN users_log l ON u.user_id = l.user_id
    WHERE l.action = 'buy'
    GROUP BY u.user_id, reg_date, activity_date
),
day_numbers AS (
    SELECT 
        reg_date,
        (activity_date - reg_date) AS day_number,
        COUNT(DISTINCT user_id) AS users
    FROM user_activity
    WHERE activity_date >= reg_date
      AND activity_date <= reg_date + 7
    GROUP BY reg_date, day_number
)
SELECT 
    reg_date,
    day_number,
    users,
    FIRST_VALUE(users) OVER (PARTITION BY reg_date ORDER BY day_number) AS day0_users,
    ROUND(100.0 * users / FIRST_VALUE(users) OVER (PARTITION BY reg_date ORDER BY day_number), 2) AS retention_rate
FROM day_numbers
ORDER BY reg_date, day_number;


Глава 14. COUNT(DISTINCT), CASE, CTE. Воронка событий

Задание: Постройте воронку для действий: enter → add_to_cart → buy (без show). Измените запрос, убрав show.

Ответ:

text
WITH user_actions AS (
    SELECT DISTINCT
        user_id,
        action
    FROM users_log
),
user_flags AS (
    SELECT 
        user_id,
        MAX(CASE WHEN action = 'enter' THEN 1 ELSE 0 END) AS has_enter,
        MAX(CASE WHEN action = 'add_to_cart' THEN 1 ELSE 0 END) AS has_add_to_cart,
        MAX(CASE WHEN action = 'buy' THEN 1 ELSE 0 END) AS has_buy
    FROM user_actions
    GROUP BY user_id
),
funnel_counts AS (
    SELECT 
        COUNT(*) AS total_users,
        SUM(has_enter) AS enter_count,
        SUM(has_add_to_cart) AS add_to_cart_count,
        SUM(has_buy) AS buy_count
    FROM user_flags
)
SELECT 
    total_users,
    enter_count,
    ROUND(100.0 * enter_count / total_users, 2) AS enter_to_total,
    add_to_cart_count,
    ROUND(100.0 * add_to_cart_count / enter_count, 2) AS add_to_cart_to_enter,
    buy_count,
    ROUND(100.0 * buy_count / add_to_cart_count, 2) AS buy_to_add_to_cart
FROM funnel_counts;


Глава 15. LAG, EXTRACT. Среднее время между enter и buy

Задание: Посчитайте среднее время между add_to_cart и buy. Измените фильтр в filtered_log и условия в WHERE.

Ответ:

text
WITH filtered_log AS (
    SELECT 
        user_id,
        action,
        dt_tm
    FROM users_log
    WHERE action IN ('add_to_cart', 'buy')
),
with_prev AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        LAG(dt_tm) OVER (PARTITION BY user_id ORDER BY dt_tm) AS prev_dt_tm,
        LAG(action) OVER (PARTITION BY user_id ORDER BY dt_tm) AS prev_action
    FROM filtered_log
),
cart_buy_pairs AS (
    SELECT 
        user_id,
        prev_dt_tm AS cart_time,
        dt_tm AS buy_time,
        EXTRACT(epoch FROM (dt_tm - prev_dt_tm)) / 60 AS minutes_diff
    FROM with_prev
    WHERE action = 'buy' AND prev_action = 'add_to_cart'
)
SELECT 
    COUNT(*) AS total_pairs,
    ROUND(AVG(minutes_diff), 2) AS avg_minutes
FROM cart_buy_pairs;

Глава 17. ROW_NUMBER, LAG. Сессии пользователей

Задание: Измените порог сессии на 15 минут вместо 30 и посчитайте, как изменилось количество сессий у пользователей.

Ответ:

text
/* Меняем условие > 30 на > 15 в session_starts */
WITH prev_time AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        LAG(dt_tm) OVER (PARTITION BY user_id ORDER BY dt_tm) AS prev_dt_tm
    FROM users_log
),
session_starts AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        CASE 
            WHEN prev_dt_tm IS NULL THEN 1
            WHEN EXTRACT(epoch FROM (dt_tm - prev_dt_tm)) / 60 > 15 THEN 1
            ELSE 0
        END AS is_new_session
    FROM prev_time
),
session_numbers AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        SUM(is_new_session) OVER (PARTITION BY user_id ORDER BY dt_tm) AS session_id
    FROM session_starts
),
session_stats AS (
    SELECT 
        user_id,
        session_id,
        MIN(dt_tm) AS session_start,
        MAX(dt_tm) AS session_end,
        COUNT(*) AS actions_count,
        EXTRACT(epoch FROM (MAX(dt_tm) - MIN(dt_tm))) / 60 AS duration_minutes
    FROM session_numbers
    GROUP BY user_id, session_id
)
SELECT 
    user_id,
    COUNT(*) AS sessions_count,
    SUM(actions_count) AS total_actions,
    ROUND(AVG(duration_minutes), 2) AS avg_session_duration_minutes
FROM session_stats
GROUP BY user_id
ORDER BY sessions_count DESC;

      SELECT 1
      FROM users_log l3
      WHERE l3.user_id = l1.user_id
        AND l3.action = 'buy'
        AND l3.dt_tm > l1.dt_tm
  );


Глава 19. DATE_TRUNC, COUNT(DISTINCT). DAU по дням

Задание: Посчитайте MAU (уникальных пользователей по месяцам) и добавьте процент изменений по сравнению с предыдущим месяцем. Используйте LAG.

Ответ:

text
WITH monthly AS (
    SELECT 
        DATE_TRUNC('month', dt_tm) AS month,
        COUNT(DISTINCT user_id) AS mau
    FROM users_log
    GROUP BY DATE_TRUNC('month', dt_tm)
)
SELECT 
    TO_CHAR(month, 'YYYY-MM') AS month,
    mau,
    LAG(mau) OVER (ORDER BY month) AS prev_month_mau,
    ROUND(
        100.0 * (mau - LAG(mau) OVER (ORDER BY month)) / 
        NULLIF(LAG(mau) OVER (ORDER BY month), 0),
        2
    ) AS percent_change
FROM monthly
ORDER BY month;


Глава 20. CASE. Bounce rate

Задание: Посчитайте bounce rate отдельно для действий enter (заход на сайт). Сессия считается отказной, если после enter не было других действий.

Ответ:

text
WITH prev_time AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        LAG(dt_tm) OVER (PARTITION BY user_id ORDER BY dt_tm) AS prev_dt_tm
    FROM users_log
),
session_starts AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        CASE 
            WHEN prev_dt_tm IS NULL THEN 1
            WHEN EXTRACT(epoch FROM (dt_tm - prev_dt_tm)) / 60 > 30 THEN 1
            ELSE 0
        END AS is_new_session
    FROM prev_time
),
session_numbers AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        SUM(is_new_session) OVER (PARTITION BY user_id ORDER BY dt_tm) AS session_id
    FROM session_starts
),
session_actions AS (
    SELECT 
        user_id,
        session_id,
        COUNT(*) AS actions_count,
        MIN(action) AS first_action,
        CASE 
            WHEN COUNT(*) = 1 AND MIN(action) = 'enter' THEN 1
            ELSE 0
        END AS is_bounce_enter_only
    FROM session_numbers
    GROUP BY user_id, session_id
)
SELECT 
    COUNT(*) AS total_sessions,
    SUM(is_bounce_enter_only) AS bounce_sessions,
    ROUND(100.0 * SUM(is_bounce_enter_only) / COUNT(*), 2) AS bounce_rate_enter
FROM session_actions;

Глава 43. MERGE. Обновить остатки или вставить новый

Ответ:

text
MERGE INTO inventory AS target
USING (
    SELECT 
        product_id, 
        SUM(quantity) AS sold_quantity
    FROM order_items_stack
    GROUP BY product_id
) AS source
ON target.product_id = source.product_id
WHEN MATCHED THEN
    UPDATE SET 
        stock = target.stock - source.sold_quantity,
        last_updated = CURRENT_DATE
WHEN NOT MATCHED THEN
    INSERT (product_id, stock, last_updated)
    VALUES (source.product_id, -source.sold_quantity, CURRENT_DATE);

text
WITH quarterly_avg AS (

        ROUND(AVG(amount), 2) AS avg_amount
    FROM payments
    GROUP BY DATE_TRUNC('quarter', payment_date)
)

    ) AS percent_change

Глава 51. COUNT(DISTINCT), JOIN, CTE, CASE. Конверсия из add_to_cart в buy

Задание: Посчитайте конверсию из добавления в корзину в покупку для каждого месяца. Используйте DATE_TRUNC('month', dt_tm) и группировку.

        DATE_TRUNC('month', dt_tm) AS month,
        user_id

),

Глава 52. LAG, EXTRACT, AVG. Среднее время между add_to_cart и buy

Задание: Посчитайте среднее время между add_to_cart и buy только для тех случаев, когда разница меньше 60 минут (исключая аномалии).

Ответ:

text
WITH events AS (
    SELECT 
        user_id,
        action,
        dt_tm,
        LAG(action) OVER (PARTITION BY user_id ORDER BY dt_tm) AS prev_action,
        LAG(dt_tm) OVER (PARTITION BY user_id ORDER BY dt_tm) AS prev_dt_tm
    FROM users_log
    WHERE action IN ('add_to_cart', 'buy')
),
cart_buy_pairs AS (
    SELECT 
        user_id,
        prev_dt_tm AS cart_time,
        dt_tm AS buy_time,
        EXTRACT(epoch FROM (dt_tm - prev_dt_tm)) / 60 AS minutes_diff
    FROM events
    WHERE action = 'buy' AND prev_action = 'add_to_cart'
)
SELECT 
    COUNT(*) AS pairs_count,
    ROUND(AVG(minutes_diff), 2) AS avg_minutes
FROM cart_buy_pairs
WHERE minutes_diff < 60;
